# Dental X-rays: Tooth Detection and Classification

This repository contains a **Deep Learning-based pipeline** to detect and classify teeth from dental X-rays. The system employs image processing techniques and convolutional neural networks (CNNs) to identify tooth regions and classify them into categories such as healthy, decayed, or impacted. The project aims to assist dental professionals in diagnosing and treatment planning.

---

## Features

- **Tooth Detection**: Automated segmentation of individual teeth from X-ray images using image preprocessing and bounding box detection.
- **Tooth Classification**: Classification of detected teeth into predefined categories using a deep convolutional neural network.
- **Preprocessing Pipelines**: Includes denoising, contrast adjustment, and morphological operations for optimal feature extraction.
- **Evaluation Metrics**: Provides performance metrics like precision, recall, F1-score, and confusion matrix for assessing model accuracy.
- **Visualization Tools**: Includes methods for overlaying detected bounding boxes and classifications on X-ray images.

---

## Technologies Used

- **Programming Language**: Python  
- **Deep Learning Framework**: TensorFlow/Keras  
- **Image Processing**: OpenCV, Pillow  
- **Data Visualization**: Matplotlib, Seaborn
